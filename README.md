# ✨ Navnidhi Salon — Beauty & Elegance

A modern and elegant salon website designed to showcase beauty services through a clean layout, aesthetic visuals, and a luxurious ivory-and-beige colour palette.

**Navnidhi Salon** is a website project created to present salon services in an attractive, organised, and user-friendly way, helping customers explore available treatments and connect with the salon.

## 🌸 About the Project

Navnidhi Salon is a full-service women's salon website prototype that combines beauty, elegance, and simplicity. The design focuses on a calm, premium aesthetic while making it easy for visitors to discover salon services and view the service catalogue.

The website aims to provide a polished online presence for the salon and improve how customers explore its offerings.

## ✨ Features

- **Elegant UI Design:** A sophisticated ivory-and-beige colour scheme.
- **Service Catalogue:** An organised display of salon services and treatments.
- **Hair Styling:** Services and inspiration for different hairstyles.
- **Facials & Skincare:** A dedicated showcase for skincare treatments.
- **Bridal Makeup:** A presentation of bridal beauty services.
- **Nails & Lashes:** A visual catalogue of nail and lash services.
- **Spa & Wellness:** A section highlighting relaxation and wellness treatments.
- **Responsive Layout:** Designed with a focus on clear presentation across different screen sizes.
- **Client Reviews:** A dedicated section to showcase customer feedback.
- **Contact & Booking:** Contact details and booking options to help customers enquire about services.

## 🛠️ Technologies Used

- **HTML5** — Website structure and content.
- **CSS3** — Styling, layouts, spacing, typography, and visual design.
- **JavaScript** — Interactive functionality, where implemented.

## 🎨 Design Concept

The website follows a quiet-luxury design approach.

- **Colour palette:** Ivory, beige, and complementary neutral shades.
- **Visual style:** Minimal, elegant, and feminine.
- **Layout:** Clean sections with organised service cards and imagery.
- **User experience:** Easy navigation and clear presentation of services.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/kritikasharma18/Navnidhi_Salon_Web_Project.git
```

### 2. Open the project folder

```bash
cd Navnidhi_Salon_Web_Project
```

### 3. Run the website

If the project uses plain HTML, CSS, and JavaScript:

1. Open the project folder in Visual Studio Code.
2. Locate the main HTML file, usually `index.html`.
3. Open it in your browser, or use the Live Server extension in VS Code.

No package installation is required for a basic static website unless the project includes additional dependencies.
